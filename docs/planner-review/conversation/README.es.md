# Conversación general acotada

[English](README.md) | [Español](README.es.md)

La respuesta general expone exactamente acción, idioma y respuesta, sin mezclar
operaciones. El contexto es limitado; la salida se marca como información general,
no como datos personales o web verificados. No confirma propuestas, ejecuta acciones
del sistema ni escribe Engram. El ciclo de captura se trata por separado.

```bash
python -B -m unittest tests.test_planner_conversation tests.test_planner_presentation
```

Los mocks no demuestran veracidad ni aceptación real. Las issues siguen abiertas.
