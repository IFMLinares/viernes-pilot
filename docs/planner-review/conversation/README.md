# Bounded general conversation

[English](README.md) | [Español](README.es.md)

General replies expose exactly action, language and answer, not mixed record
operations. Session context is bounded; answers are labelled general information,
not verified personal records or web results. Replies cannot confirm proposals,
execute OS tools or write Engram. Later capture-lifecycle work remains separate.

```bash
python -B -m unittest tests.test_planner_conversation tests.test_planner_presentation
```

Mocked correctness is not factual or real-model acceptance. Known issues stay open.
