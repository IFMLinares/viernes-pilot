# Referencia pública y guías manuales

[English](README.md) | [Español](README.es.md)

Esta unidad publica referencia, recorridos manuales bilingües y guía de evaluación
de la candidata. Distingue aislamiento sintético, confirmación, evidencia simulada
y aceptación real. Se excluyen informes históricos y notas privadas.

Las guías emparejadas permanecen juntas con la excepción autorizada. No cambia
comportamiento ni presupuesto de inferencia. #3–#6 siguen abiertas; insertar
manualmente no sustituye la conversación que se está probando.
